# Tracebench

**Write-up:** https://yashgix.github.io/tracebench/

A benchmark for on-call AI agents. A small shop with three services and a real git history has six incidents in it.
Each one fires a page; a model reads the logs, traces and code, then fixes the problem, escalates it or dismisses it.
Every fix is checked outside the model's reach by the shop's tests, hidden tests and a replay of the same traffic.

This repository holds only the write-up page. Source code on request.
